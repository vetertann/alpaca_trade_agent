- Format: online, 7 days. Teams 1–6 people.

## The challenge — "Options Alpha Agents"
Build an autonomous AI trading agent that generates P&L on Alpaca paper trading.

### Hard requirements
1. Autonomous AI trading agent using Alpaca's **Trading API**
2. Must use **Alpaca MCP server OR Alpaca CLI**
3. **All strategies must incorporate options trading**
4. **Fresh, brand-new paper account** created for the hackathon — reused/existing accounts are NOT eligible
5. Starting balance set to **$100,000**
6. One-page write-up: AI logic, risk gates, Alpaca infrastructure implementation

### Submission checklist
- Title, short + long description, tech/category tags
- Cover image, video presentation, slide deck
- Public GitHub repo, demo app platform + application URL
- **Alpaca paper trading account ID** (required for judging / P&L verification)
- Optional: up to 5 links to X/LinkedIn posts (tag @lablabai + @AlpacaHQ)

## Judging criteria
1. **P&L performance** in the paper environment
2. **Technology implementation** (Trading API, MCP, CLI)
3. **Creativity & originality** (strategy, agent behavior)
4. **Presentation & execution**
5. **Social engagement** (post quality + likes/comments/shares)

## Prizes — $6,300 pool (paid by AlpacaDB, Inc., USD)
